Traditional photon-distribution estimators, declared before fitting, 2026-10-28 UTC

Question
Do simple count-aware statistical methods match the neural photon-arrival
predictors on the same P-ONE pilot? The already frozen mixture is a classical
comparator and is already better on the all-photon score. Do not assume that
the new traditional estimators will be worse than the neural model.

Method families
1. Dirichlet-multinomial empirical-prior posterior prediction:
   q=(A+alpha*pi)/(N_A+alpha).
2. Temporal Gaussian KDE per detector, with prior shrinkage.
3. Spatial/time Gaussian KDE using actual Euclidean x/y/z detector distances,
   with prior shrinkage. No arbitrary sensor-index adjacency is used.
4. Poisson likelihood plus anisotropic time/vertical TV, followed by shape
   normalization and prior shrinkage. Vertical differences join physical
   neighbors on the same detector string, with no edges between strings or
   across dead sensors. This is not a full Cherenkov track-likelihood fit.
Also report the independently selected population prior as an input-free control.

For KDE, normalize each source kernel column on the finite live support so
every photon retains unit mass at spatial/time boundaries. Consider both
fixed bandwidth and N_A^(-1/(d+4)) sample-size scaling, d=1 for temporal and
d=4 for joint kernels. Physical base bandwidths are selected on inner data;
this is not automatic sample-covariance estimation. Every output is one
joint PMF over live sensor/time bins. Empty A uses the population prior.
Prior concentration is in observed-photon count units. TV intensity mass is
restored to N_A before applying the same concentration rule.

Poisson-TV numerical contract
Minimize sum(u-A log u)+beta*(||D_time u||_1+||weighted D_vertical u||_1), u>=0.
Use Chambolle-Pock with theta=1 and tau=sigma=.99/sqrt(4*(1+max_weight^2)).
The Poisson proximal operator is exact and stabilized for negative arguments.
Check a feasible-dual primal/dual gap every 50 iterations, normalized per
observed A photon. Tune with at most 2000 iterations and gap tolerance 1e-4;
explicitly exclude nonconverged candidate densities, without replacing them
with unreported approximations. For locked inference, numerical refinement
may use up to 20000 iterations at the same tolerance, independently of B.
Fail an estimator rather than claiming convergence if refinement still fails.

Metrics and reporting
Report photon-weighted held-out NLL and mean cross entropy per nonempty target
for all observations and the retained-A 1-10 count subset. Compare with the
frozen 4D predictor, released GAP network under both training setups, full-time
control and the historical frozen mixture. The latter had been validation-
tuned earlier and is labeled accordingly. Classical estimates are deterministic;
neural seed scores are averaged before comparisons, without replicating events.
Use the same 10000 whole-configuration bootstrap draws, seed 20261027, for
conditional 4D-minus-classical intervals, including equal-event contrasts.
Intervals omit parameter-selection/seed uncertainty. The outer cohort has
been explored before; this is not a fresh independent test.

Run on GPU 0 only, float64 for classical estimation, four CPU threads. Record
tuning and prediction wall times, convergence diagnostics and GPU allocation.
These times are not directly equivalent to neural training time. Save locked
settings, split IDs, priors, full prediction fields, event scores and code/
data/reference identities. Replay predictions to audit scores and probability
mass on every validation event. Export comparison figures and fixed input-
stratum examples to the existing localhost:8765 server.

No reserved test photon arrays, MC truth, source labels, clean photon GT, PSNR
or event-detection labels are used. Outputs are relative arrival probabilities,
not event-presence probabilities or an absolute photon-rate estimate.
